## 1. Creating work

- **Google Classroom** (GC/6020265): Create offers Assignment, Question,
  Material, Reuse post. Main column: title, instructions, Add/Create
  attachments (Drive, YouTube, link, upload, new Doc, record) with per-file
  sharing ("Make a copy for each student"). Right rail: For (classes, all or
  some students, groups), points (100 default or Ungraded), due (no due date
  default), one topic (created inline), rubric, grade category. Split button
  Assign ▾ Schedule / Save draft. Several classes get per-class dates and
  topic with "Copy settings to all"; copies are then independent. Reuse post
  (GC/6272593) can copy attachments. Only the title is required; defaults make
  Assign valid immediately; late submissions became a single toggle in 2023.
- **Microsoft Teams** (MS/create-an-assignment-in-microsoft-teams): only the
  title required; dates collapse into one sentence ("Assignment will post
  immediately with late turn-ins allowed") that expands into schedule, due,
  close and per-class due. Default due time is a class setting; "From
  existing" reuses work, even from archived classes.
- **Canvas**: quick shell (type, name, due, points) with Save or Save &
  Publish and More Options (CV/660665); settings carry over from the previous
  assignment (CV/660674); Assign To rows each with due, available from and
  until (CV/660688); late and missing policies per course (CV/660858, CV/660857).
- **Moodle** shows every settings section at once (MD/Assignment_settings):
  the anti-pattern for non-technical teachers.
- **Seesaw**: voice or video instructions (SS/360057131152), example pages,
  Preview as Student, class/group/student audience with start and due
  (SS/17964278341005), Repeat Activity (SS/17964702107917).

## 2. Where coursework lives

- Classroom: Stream feed (classwork can be condensed or hidden, GC/6076302);
  Classwork grouped by topic; student To-do with Assigned / Missing / Done
  (GC/6020284); teacher To review across classes (GC/9157286); assignment page
  with Instructions and Student work and turned-in counters (GC/6020294).
- Teams: teachers Upcoming / Ready to grade / Past due / Drafts / Returned;
  students Upcoming / Past due / Completed.
- Canvas: teacher To Do is everything to grade (CV/662821); student labels
  Missing / Late / Graded / Redo (CV/662819).
- Parents: Classroom guardians get email plus a Classwork preview, no Stream or
  grades (GC/7126518); Schoology parents switch into the child's view
  (SC/home-page-overview-parents); Teams has only a digest.

## 3. Handing in

- Classroom (GC/6020285): Add or create, Turn in with confirmation; Mark as
  done when nothing to attach; Unsubmit; turning in after due is late;
  statuses Assigned, Missing, Turned in, Done late, Returned; turned-in Docs
  become view-only until returned (GC/6020260).
- Teams: the button changes with state: Turn in, Turn in late, Turn in again,
  Undo turn in.
- Canvas: Start Assignment, Submit, New Attempt, a progress tracker, confetti
  for on-time work (CV/661210, CV/661237).
- Pre-readers: Seesaw QR or class-code sign-in and tap your name (SS/203495019);
  camera, drawing and voice canvas, a big green check, autosave; drafts and
  Send Back don't work with shared-device sign-in (SS/360035817912).
  Schoology Elementary: five response types and "I'm Done!".

## 4. Grading

- Classroom grading tool (GC/9093530): student dropdown with back/next, the
  file in the middle with inline comments, a side panel with grade, private
  comments, comment bank ("#"), rubric. Grades are drafts until Return, which
  works in bulk (GC/6020294). Red missing, green turned in or draft grade,
  black returned. Excuse, Mark as missing, Mark as complete.
- Canvas SpeedGrader (CV/661158): student list with graded dots sortable by
  status; a status menu (Late, Missing, Excused); comment library suggesting
  after three characters (CV/664291); keyboard shortcuts behind Shift+?;
  scores autosave but comments must be submitted (CV/664292), a trap.
- Teams: inline points and feedback in the list; bulk Return or Return for
  revision ("Needs revision"); Mark as excused and return.
- Seesaw: an approval queue before families see work (Approve All, Send Back).

## 5. Rubrics

- Classroom (GC/9335069): criteria by levels, each level title, description,
  points (up to 50 × 10); Use scoring switch; reuse, import from Sheets,
  generate; locked once grading starts; grading clicks a level per criterion,
  total auto-filled and overridable (GC/9335428).
- Canvas enhanced rubrics: library with saved and archived; scale or written
  feedback; scored or unscored; point ranges (CV/661106, CV/661107); a shared
  rubric cannot be edited.
- Teams: default levels Excellent/Good/Fair/Poor, weights totalling 100,
  rubrics saved to a list; AI output follows the interface language.
- Moodle: preview before grading; editing after grading forces a regrade
  (MD/Rubrics).

## 6. Notifications and families

- Classroom guardian summaries daily (Mon–Fri) or weekly, in the guardian's
  timezone: missing, upcoming, class activity; no grades; skipped when empty;
  off by default per class (GC/6386354, GC/6388136, GC/6388126).
- Teams: weekend digest of turned-in and missing work and next week's due
  dates; off by default; needs School Data Sync.
- Schoology: digest with grades plus one email per overdue item that
  guardians cannot switch off.
- Canvas: per type immediate, daily, weekly or off; immediate held 30–60
  minutes; parent app alerts for low grades and missing work (CV/387041,
  CV/661795).
- ManageBac: each parent chooses interface language (MB/360019111271).
- Seesaw: family access off by default; families see approved work only;
  translating an activity makes a copy.

## 7. Pitfalls

- The due-minute boundary: work at 11:59 counted late (GCT/378726249); Google
  advises 9:01 for work due at 9:00.
- Misunderstood late settings (GCT/118568396) and contradicting help articles.
- Wrong Missing labels (GCT/43292451); offline work never auto-missing, one
  teacher marking missing by hand "50,000 times".
- No Excused status for four years in Classroom (GCT/3862757).
- Two visibility switches (Canvas publish and post grades; ManageBac shows
  grades immediately).
- Edits that delete work (Canvas unassigning deletes submissions).
- Per-item email spam; hard-to-enable parent access; translation by copy;
  English-only AI.

## Resulting specification

Principles: one status vocabulary everywhere; one visibility verb per object
(Assign publishes, Return releases); title and brief are enough to assign;
no edit destroys student work; families on by default with a digest.

Learner states (one server function): To do, In progress, Handed in, Handed
in late, Missing (from the due time, still submittable while late work is
accepted), Needs revision (reopens hand-in), Returned, Excused. Teachers also
see Not yet available and Draft grade. Assignment states: Draft, Scheduled,
Assigned, Past due, Closed, Archived. A short grace period absorbs the due
boundary.

Pages: Coursework list (To grade, Assigned, Scheduled, Drafts, Past); editor
(title, brief, resources; side panel with class, audience chips, due with quick
picks, points or Ungraded, topic, rubric; a summary sentence; More options;
Assign or Schedule; Preview as student; one copy per class); assignment record
(Brief, Student work with bulk Return, Return for revision, Excuse, Remind);
grading view (student list, submission and attempts, score, rubric levels,
feedback with comment bank, private comments, autosaved drafts, Return & next,
Needs revision, J/K); rubric library (criteria by levels, scoring toggle,
copies on attach, points lock once grading starts). Student To do (To do,
Missing, Done, grouped by day, young mode with audio) and assignment view
(Your work with autosave and attachments, Hand in with confirmation and
receipt, Undo, returned results, Mark as done). Family coursework (Missing,
due this week, recently returned; no draft grades) and a weekly digest in the
parent's language. Admin oversight of missing work and load.

Gaps found in the current model: Missing never appears when late work is
accepted without a close date; no Excused, Needs revision or Handed-in-late;
no ungraded work; no on-paper or no-hand-in formats; rubric criteria without
levels and a forced equal total; only `assignment_published` and
`assessment_released` notifications.
