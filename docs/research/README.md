# Research

The evidence behind the rebuild of Farida LMS, gathered from primary sources in
September 2026. Specifications cite these files; change a specification only
with new evidence recorded here.

- [decisions.md](decisions.md): what was decided, with whom, and why.
- [ui-patterns.md](ui-patterns.md): editor pages, forms, fields, status, index
  pages, top bar, type and spacing (Polaris, Primer, Atlassian, Carbon, GOV.UK,
  NN/g, Notion, Linear, shadcn). Rules: [../design-system.md](../design-system.md).
- [coursework.md](coursework.md): creating, handing in, grading, rubrics and
  family visibility (Classroom, Canvas, Teams, Schoology, Seesaw, Moodle).
- [communication.md](communication.md): messaging, announcements, newsletters,
  calendar, notifications (ParentSquare, Remind, ClassDojo, Seesaw, Bloomz,
  Brightwheel, Mailchimp, Smore).
- [administration.md](administration.md): directories, records, enrolment,
  attendance, timetable, rollover, roles (PowerSchool, Arbor, Veracross,
  Blackbaud, Toddle, ManageBac, Moodle, Canvas).
- [navigation-and-content.md](navigation-and-content.md): role home pages,
  navigation, the class hub, modules and lessons, the school website.
- [backend-architecture.md](backend-architecture.md): standards (OneRoster,
  Ed-Fi, LTI), tenancy, API, auth, jobs, real-time, files, search, law.
- [editor-engines.md](editor-engines.md): the content editor engine choice.

Product behaviour built from these: [../product-spec.md](../product-spec.md).
