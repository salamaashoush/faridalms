# Editor engine comparison

Measured on 2026-09-26 by bundling each candidate with
`bun build --minify --production --conditions=production` and gzipping the
result. Figures are for the whole package surface, before tree-shaking.

| Option                | gzip                                         | Strengths                                                                                                                                                                            | Weaknesses                                                                                                                                                   |
| --------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Lexical core          | 63 KB (94 KB with rich text, lists, history) | MIT, maintained by Meta; official Yjs binding; draggable blocks, typeahead and node menus ship in `@lexical/react`; per-block direction; our stored content was already Lexical JSON | pre-1.0 API churn; Notion-style UI must be built; collaboration less mature than ProseMirror's; one stress test reported memory growth in very long sessions |
| ProseMirror           | 64 KB                                        | most mature collaboration (`y-prosemirror`); strict schema                                                                                                                           | steep learning curve; awkward React node views; full content migration                                                                                       |
| TipTap                | 123 KB                                       | fastest route to a product editor; large extension set                                                                                                                               | some features paid; a layer over ProseMirror; full migration                                                                                                 |
| BlockNote             | 389 KB                                       | Notion UX out of the box                                                                                                                                                             | heaviest; Mantine/Ariakit/Radix UI kits (we use Base UI); its own block schema; multi-column and export are GPL or commercial; full migration                |
| Slate / Plate         | 59 KB                                        | small and flexible                                                                                                                                                                   | weakest IME, Android and contenteditable handling, which matters for Arabic; community collaboration only; full migration                                    |
| From scratch          | n/a                                          | none                                                                                                                                                                                 | years of selection, IME, clipboard, mobile and bidi edge cases; no speed gain, since reconciliation is the cost Lexical already optimises                    |
| Yjs (CRDT)            | 28 KB                                        | bindings for Lexical and ProseMirror                                                                                                                                                 | —                                                                                                                                                            |
| Loro (CRDT)           | 1 MB wasm                                    | fast for huge documents                                                                                                                                                              | too heavy for school phones                                                                                                                                  |
| Excalidraw (drawings) | about 2.4 MB with lazy chunks                | MIT, React 19, easy for non-technical users                                                                                                                                          | heavy, so it loads only when the drawing board opens; readers see a PNG                                                                                      |

At the time of the audit the web app shipped Lexical inside its main 372 KB
gzip bundle; the editor is now code-split so reading pages never load it.

Lexical v0.50.0 source (playground plugins, `@lexical/yjs`), Hocuspocus and
